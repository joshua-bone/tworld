Why completion is impossible

  1. Both decoded layers contain zero actual Exit tiles (DAT file code 21 / MS_TILE.Exit). The 212 Exited_Chip tiles (DAT 57) are decorative solid tiles, not exits.
  2. The normal MS completion transition requires Chip alive with an actual Exit under Chip after an arrival. Collecting all 64 chips alone does not complete a level.
  3. No game operation available in this level creates an Exit from another tile. There are no cloners, blocks, teleports, or buttons. Thus the exit-absence invariant holds for every play.
