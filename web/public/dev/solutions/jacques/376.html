Winning strategy

  1. Keep the Empty-over-Water bridge at (1,8),(2,8) unused. Wait until a Teeth covers the upper teleport (0,7), then enter the lower teleport southward. Because MS skips covered teleport destinations, Chip emerges onto the outer force-floor circuit. The replay uses random seed 67 and starts this maneuver at tick 85.
  2. Collect the right-island chip (23,16), return through the original right-island entrance, then collect the center chip (19,17) and lower-left chip (17,16). Hidden chips require leaving and reentering after the covering Empty tile disappears.
  3. Return to the left force lane with a gap behind another creature. At tick 742, left-click visible tile (0,10). Chip begins this tick at (0,12); forced movement puts him at (0,11), and the mouse goal adds a north step to (0,10). The original mouse handler emits absolute command 832, which the live engine records as relative mouse command 177. This reaches the brief window where the upper teleport is covered, so teleportation fails and Chip advances onto starting Gravel (0,8) at tick 746.
  4. Cross the preserved bridge, collect the final hidden chip (14,8), then open socket (17,8), leave and reenter for the flippers beneath it. Swim to exit (31,0).
  5. The corrected TWS contains only original MS cardinal keyboard commands and one mouse command. It completes the unchanged DAT in both engines at tick 920 with all four chips collected. The full native and TypeScript traces match.

Scope and limitations
  • This is a verified original Tile World MS solution, with a matching TWO replay. It is not a verified Microsoft CHIP.EXE solution. The earlier diagonal replay is withdrawn as a player-valid solution.
  • SuCC rejects the required extra mouse step even when supplied the intended absolute target. Changing only the replay's relative mouse coordinates is therefore insufficient. The comparison establishes an engine difference; it does not establish which implementation matches Microsoft CHIP.EXE. A cardinal-keyboard-only solution remains under investigation.
