Why completion is impossible

  1. Both raw DAT planes contain zero file-code 21 (Exit), verified over all 2048 tiles.
  2. Native MS endmovement is the sole place setting completed() to true, and requires the floor beneath Chip to be Exit.
  3. All transitions available in this map only move/reveal existing tiles or create fixed non-Exit tiles (empty floor, dirt, walls, actors); none produces an Exit. Cloners copy actors, not Exit terrain.
  4. By induction no reachable state contains an Exit; therefore no input sequence can satisfy the completion condition.
