# Smart Teeth artwork

Generated with the built-in OpenAI image-generation tool on 2026-10-20.
The transparent 1254 × 1254 atlas has four equal 627 × 627 frames in N/W/S/E
order. Both Tile World Online and DATTools publish the same image and manifest.

Final art brief: a green MS Teeth-style monster standing upright on two legs,
with bold red lips, sharp white triangular teeth, and a large exposed pink
brain. Crisp retro pixel art, dark outlines, transparent background, clear
directional silhouettes, no labels or floor tiles. The MS sprite sheet supplied
the anatomy reference. The first crouching-frog draft was replaced after review.

DAT bytes 0x7D–0x80 are Smart Teeth north, west, south, and east. Runtime tile
IDs 0x8C–0x8F form its aligned directional actor quartet.
